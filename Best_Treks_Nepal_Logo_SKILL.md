# Best Treks Nepal — Logo Generation Skill

## Purpose

This skill guides an AI design agent to generate a premium, professional, tourism-focused logo for **Best Treks Nepal**.

The logo must communicate:

- Nepal
- Himalayan adventure
- Trekking and exploration
- Trust and professionalism
- Premium travel experiences
- Modern digital branding

---

# 1. Brand Identity

## Brand Name

**Best Treks Nepal**

## Tagline

**ADVENTURE AWAITS**

## Brand Category

Adventure tourism, trekking, Himalayan travel, guided expeditions, and Nepal travel experiences.

## Target Audience

- International trekkers
- Adventure travelers
- Luxury and premium travelers
- Nature enthusiasts
- Mountaineering visitors
- Tourists planning a Nepal experience

---

# 2. Core Design Concept

Create a **modern vector-style Himalayan adventure logo**.

The central visual identity should combine:

1. A dramatic Himalayan mountain range
2. A rising or setting sun
3. A trekking trail or journey path
4. A small trekking explorer silhouette
5. Optional pine trees for wilderness context

The design should feel:

- Premium
- Bold
- Clean
- Memorable
- International
- Professional
- Timeless

The logo should not look like a generic stock travel icon.

---

# 3. Primary Logo Composition

## Symbol

Create a strong emblem featuring a dramatic Himalayan mountain.

Inside or around the mountain composition:

- Angular snow-covered peaks
- A warm orange sun behind the mountains
- A subtle trekking trail moving toward the mountain
- One small trekking hiker silhouette with backpack and trekking poles
- Optional minimal pine trees near the foreground

The symbol should be balanced and recognizable even at small sizes.

## Wordmark

Place the brand name below the emblem:

**Best Treks Nepal**

Use a bold modern sans-serif style.

Requirements:

- Strong weight
- Excellent readability
- Slightly wide proportions
- Premium outdoor brand feeling
- Avoid decorative or handwritten fonts

## Tagline

Place below the main wordmark:

**ADVENTURE AWAITS**

Requirements:

- Uppercase letters
- Increased letter spacing
- Smaller than the brand name
- Warm orange accent color

A thin horizontal line may separate the main name and tagline.

A small mountain peak can be placed in the center of the separator line.

# 5. Design Rules

The generated logo must:

- Be visually simple enough to work as a favicon
- Look professional on websites and social media
- Scale well from mobile to billboard size
- Work in full color
- Work in one color
- Work on light backgrounds
- Work on dark backgrounds
- Have clear visual hierarchy
- Avoid unnecessary detail

The logo must NOT:

- Look childish
- Use excessive gradients
- Use too many colors
- Look like clip art
- Look overly cartoonish
- Copy an existing company logo
- Contain cluttered visual elements
- Use thin details that disappear at small sizes
- Overuse Nepal flags or religious symbols

---

# 6. Typography Direction

Preferred style:

- Modern geometric sans-serif
- Bold
- Clean
- Premium
- High readability

Possible visual direction:

- Strong uppercase/lowercase mixed wordmark
- Heavy weight for “Best Treks”
- Slightly lighter but still bold treatment for “Nepal”

Do not use decorative script fonts.

The typography should feel similar to a professional international adventure brand rather than a local souvenir shop.

---

Use the colors #0F5257 deep teal and #F2A65A adventure orange as the main palette. The design must feel premium, modern, clean, trustworthy, adventurous, international, and timeless. Use a crisp vector logo style, balanced composition, sharp edges, minimal detail, white background, centered layout, no mockup, no paper texture, no watermark, no 3D effect.

# 12. Implementation Guidance

For the website, use:

- **Primary logo:** full-color version
- **Header logo:** horizontal or simplified primary version
- **Mobile header:** icon + short wordmark
- **Favicon:** mountain emblem only
- **Footer:** reverse white version on dark teal
- **Social profiles:** square mountain emblem

Recommended exported formats:

- SVG
- PNG with transparent background
- WebP
- 512 × 512 icon
- 1024 × 1024 master image
